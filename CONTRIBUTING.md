# Feedback and Contributions

The method is owner-maintained, with questions and feedback kept together in
Issues. You can [ask a question or share an experience](https://github.com/dowanski/dowanski-method/issues/new?template=experience.yml),
including what helped or what you adapted. To describe an instruction or file
that did not work as expected, use [Report a problem](https://github.com/dowanski/dowanski-method/issues/new?template=problem.yml).

Use the [Issues tab](https://github.com/dowanski/dowanski-method/issues) for non-sensitive feedback.
For a problem report, include the version, QDI phase or DM foundation, affected
file, expected result, what happened, and a minimal sanitized example. A general
question does not require a completed project or technical report. Separate observations from
preferences. Do not include private conversations, customer data, credentials,
internal paths, or employer-owned material without permission.

Security concerns belong in the private route described in [SECURITY.md](SECURITY.md).
Please read the [conduct expectations](CODE_OF_CONDUCT.md).

Pull requests are not invited initially while contribution and provenance
handling are established. An unsolicited PR may be closed without merging.
Feedback creates no endorsement, delivery promise, or maintenance commitment.
Dowanski retains acceptance and release authority for the canonical method.

## Maintaining this source

Read [AGENTS.md](AGENTS.md). The reusable packet lives in `starter/`; the
repository root is not an adopter project. Change one canonical source, explain
the purpose and evidence, preserve notices, and run the
[local checks](tools/README.md). Review behavioral implications as well as test
results. A passing text check does not establish the quality of an instruction.

Release-producing changes require explicit owner review. A maintainer should
verify the source, generate fresh archives, verify their contents and hashes,
and review the [release checklist](release/README.md) before requesting
publication authority. No script in this repository publishes a release.
