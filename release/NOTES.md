# v0.2.0 — First Public Edition

September 9, 2026. The first public edition of The Dowanski Method: a practical
Markdown system for human-led, agent-assisted projects.

The recommended package is the Complete starter: QDI discovery first, followed
by a human-approved handoff into one tailored DM foundation. Light, Standard,
and Governed direct ZIPs are advanced alternatives for already-established work.

## Download

Choose **dowanski-method-complete-v0.2.0.zip** to begin with QDI. The three direct
foundation ZIPs omit discovery and require accepted context and authority.

| Package | Files |
|---|---:|
| Complete | 96 |
| Light | 14 |
| Standard | 26 |
| Governed | 34 |

The totals include applicable version/license notices; they are not daily
reading requirements. The attached `SHA256SUMS.txt` covers all four ZIPs.
GitHub's generated Source code archives contain the maintainer repository,
not the recommended adopter packet. There is no automatic migration: existing
adopters should compare changes and adapt deliberately, never overwrite their
project instructions wholesale.

The package contains Markdown, not a hosted service or an automatic installer.
It requires a compatible agent environment with local-file access for automatic
record maintenance. It grants no implementation, account, or publication rights.

## Verification and boundaries

Eight local test groups pass, including reproducibility, extraction, source
parity, links, routing, license checks, and eleven injected routing/control
defects. Earlier fictional agent exercises informed the templates; the later
compressed instructions have not received a new independent-agent run.

Read [the verification statement](https://github.com/dowanski/dowanski-method/blob/v0.2.0/guides/verification.md) before interpreting
passing structural checks as behavioral proof. Report non-sensitive findings
through [the contribution process](https://github.com/dowanski/dowanski-method/blob/v0.2.0/CONTRIBUTING.md); use the private channel
for security concerns.
