## Branch packet contract

Before an approved branch becomes active, rewrite `ACTIVE_PACKET.md` or create
one named branch packet containing:

1. a durable Branch ID when the packet passes the eligibility test;
2. branch objective;
3. inherited owner-confirmed truth;
4. decision the branch must support;
5. unresolved questions;
6. evidence required;
7. permitted and prohibited actions;
8. depth;
9. sidequest triggers;
10. stop condition;
11. exact convergence destination;
12. next human gate.
