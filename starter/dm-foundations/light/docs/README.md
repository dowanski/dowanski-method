## History boundary

No archive is required until material earns historical value. Closed work is
removed from this active route and preserved through an existing, authorized
version-history system when that history is sufficient. If reliable history is
unavailable, or deletion would remove material with provenance or recovery
value, stop and ask the owner to choose an archive or preservation action.
