# Changelog

## 0.2.0 — Initial public edition / September 9, 2026

- Combined QDI discovery and inactive Light, Standard, and Governed receivers
  into one default starter, with separate advanced foundation packages.
- Added explicit phase, sidequest-return, cleanup, handoff, and human gates.
- Reduced required startup reading while retaining continuing authority,
  quality, review, and context/usage controls across the QDI-to-DM transition.
- Repaired selected navigation paths and isolated maintainer/adopter entrypoints.
- Aligned license notices with the combined folder structure.
- Added a public-facing source introduction and local packaging/verification.

Earlier development candidates were private. This file does not imply they
were published releases. The version authority is `starter/VERSION`.
